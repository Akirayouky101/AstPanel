Configurazione Google Calendar

Connetti il calendario del titolare all'AST Panel

📋 Come configurare (una volta sola):

  1. Vai su calendar.google.com → crea un nuovo calendario dedicato (es: "Richieste AST")
  2. Impostazioni calendario → "Rendi pubblico" (spunta la casella)
  3. Copia l'ID Calendario (es: xxxx@group.calendar.google.com)
  4. Vai su console.cloud.google.com → crea un progetto → abilita Google Calendar API → crea una API Key
